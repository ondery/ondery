SignLens Trainer Studio

SignLens Trainer Studio is the local training application for SignLens, an offline traffic-sign reader for iOS and Android. Önder Yıldırım built it in 2026.

It is a Python web app bound to 127.0.0.1. It is not a public website. On Windows 11 it starts from a .bat file. The training presets are tuned for a laptop NVIDIA GeForce RTX 3060 with 6 GB of VRAM, using Ultralytics and a CUDA build of PyTorch. The SignLens source is private and is not linked from this site.

What SignLens is

SignLens reads traffic signs on a phone without a network connection. It runs on iOS and Android and uses YOLO. Trainer Studio is the part of that project used to collect images, draw boxes, train weights, test them, and hand a model file to the iOS build.

Simple mode

Simple mode is a five-step wizard written in plain Turkish.

  1. Add photos and videos. Frames can be taken from a video file and from YouTube.
  2. Label signs. Draw, move, and resize boxes. Keyboard shortcuts are available. “Suggest from model” proposes boxes from an existing weights file. A readiness bar targets about 50 boxes per class.
  3. Train with a preset for a 6 GB GPU. The accuracy shown for the run is mAP50 read from results.csv.
  4. Test the weights on a new image, a video, or a camera.
  5. Send the model to an iPhone. The step writes ios/signlens.pt. Codemagic converts that file to Core ML.

Presets for a 6 GB GPU

Three presets are published. Only the values in this table are part of that description. Image size is stated for Quick. Batch size is stated for Quick and Best. Normal is stated as an epoch count.

Training presets tuned for a 6 GB GPU (RTX 3060).
Preset Epochs Model Image size Batch
Quick 10 yolo11n 640 8
Normal 50 Not stated in the preset summary Not stated in the preset summary Not stated in the preset summary
Best 100 yolo11s Not stated in the preset summary 4

Where the accuracy number comes from

The studio reads mAP50 from results.csv after a run. It does not invent a score. This page does not publish a mAP figure, because no measured result is part of the project description used here. Expert mode can also show mAP50-95, precision, recall, and the training losses from the same run, plus the confusion matrix.

Expert mode

Expert mode opens the training controls that simple mode keeps behind a preset.

  • Hyperparameters: epochs, imgsz, batch, lr0, optimizer, patience, device, and augmentation.
  • Inference thresholds: confidence and IoU.
  • Raw YOLO label files.
  • mAP50-95, precision, recall, losses, and the confusion matrix.
  • Live logs and a comparison of runs.
  • Export to .pt, ONNX, and Core ML.
  • A git push of the model and the sign catalog.

Datasets

Roboflow YOLOv8 zip files

A Roboflow YOLOv8 zip opens a class-mapping screen. The screen auto-suggests familiar sign classes such as speed limits, stop, and no_entry. The mapping is confirmed before import.

GTSDB and GTSRB

Large GTSDB and GTSRB archives are imported from disk. The import shows progress and can be cancelled. It enforces a 20 GB limit and includes zip-bomb protection.

Sign catalog

The Sign Catalog includes Turkish, German, and Vienna sign artwork. A new sign class can be added by uploading an SVG or a PNG, or by searching Wikimedia Commons. The license and the author credit are written through so the iOS app can show them.

Vehicle-specific speed limits

Some signs are a panel of several limits, one per vehicle. The studio labels the panel, the speed circles, and the vehicle icons. The icons are car, panel van, minibus, bus, pickup, and truck. The user links each circle to an icon by hand, or uses auto-link. The studio then resolves one phrase per vehicle, for example “Otomobil: 110”. That mapping is exported to the app as vehicle_rules.

Tests

The project is tested with pytest.

Questions about Trainer Studio

What is SignLens Trainer Studio?

SignLens Trainer Studio is a local, browser-based YOLO training studio for the SignLens project. It is a Python web app bound to 127.0.0.1, started with a .bat file on Windows 11, and tuned for a laptop NVIDIA GeForce RTX 3060 with 6 GB of VRAM, using Ultralytics and a CUDA build of PyTorch.

What is SignLens?

SignLens is an offline traffic-sign reader for iOS and Android that uses YOLO. Trainer Studio is the part of SignLens used to label images, train weights, test them, and prepare a model file for the iPhone app.

What happens in simple mode?

Simple mode is a five-step wizard written in plain Turkish. You add photos or videos, including frames taken from a video file or from YouTube; label signs; train with a preset for a 6 GB GPU; test on a new image, a video, or a camera; then send the model to an iPhone.

Which training presets are published for a 6 GB GPU?

Quick runs 10 epochs of yolo11n at image size 640 and batch 8. Normal runs 50 epochs. Best runs 100 epochs of yolo11s at batch 4.

Where does the accuracy number come from?

The accuracy shown after training is mAP50 read from results.csv. The studio does not invent metrics. Expert mode can also show mAP50-95, precision, recall, and the training losses from that same run.

How does the model get onto an iPhone?

The send step writes ios/signlens.pt. Codemagic converts that file to Core ML for the iOS app.

Which datasets can be imported?

Roboflow YOLOv8 zip files open a class-mapping screen that auto-suggests classes such as speed limits, stop, and no_entry. GTSDB and GTSRB archives can be imported from disk, with a progress indicator, cancel, a 20 GB size limit, and zip-bomb protection.

How are vehicle-specific speed limits labeled?

The studio labels the panel, the speed circles, and the vehicle icons — car, panel van, minibus, bus, pickup, and truck — then links them manually or with auto-link. It resolves one limit per vehicle, for example "Otomobil: 110", and exports that mapping as vehicle_rules for the app.

How is Trainer Studio tested?

The project is tested with pytest.
